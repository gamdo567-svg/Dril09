# 방향키 캐릭터 이동 게임

Python 3 환경에서 실행한다. 이 프로젝트는 Windows의 Python 3.14와 pico2d 1.5.1에서 검증했다.

```powershell
python -m pip install -r requirements.txt
python character_runs_esc.py
```

방향키로 이동하고, 수평·수직 키를 함께 누르면 대각선으로 이동한다. ESC 또는 창 닫기로 종료한다. 같은 축의 반대 키는 상쇄된다. 창이 포커스를 잃으면 눌림 상태를 초기화한다.

화면은 배경과 같은 5:4 비율인 1000×800이며, 캐릭터 프레임과 표시 크기는 100×100이다. 이동 속도는 초당 250픽셀, Idle은 프레임당 0.15초, Run은 0.10초다. 설정은 `character_runs_esc.py` 상단에서 변경한다.

`animation_sheet.png`와 `TUK_GROUND.png`를 코드와 같은 폴더에 둔다. 다른 작업 폴더에서 절대 경로로 실행해도 리소스는 코드 위치에서 불러온다. 스프라이트 시트는 802×402이며 위쪽부터 100픽셀씩 4행, 각 행에서 왼쪽부터 100픽셀씩 8프레임을 사용한다. 오른쪽과 하단의 2픽셀 여백은 제외한다.

## 검증

```powershell
python -m unittest -v
python character_runs_esc.py --smoke-test
```

자동 검증은 네 방향과 대각선 이동, 속도 보정, 반대 입력 상쇄, 키 해제와 반복 입력, 방향 유지, 화면 경계, 애니메이션 반복과 전환, 창 포커스 해제 및 종료 이벤트를 확인한다. 스모크 검증은 실제 창에서 배경과 캐릭터를 12프레임 렌더링하고 종료한다.

수동 확인 시에는 네 방향과 대각선으로 이동한 뒤 모든 키를 놓고 Idle 전환을 확인한다. 네 모서리까지 이동한 후 경계를 따라 이동하거나 반대 방향으로 돌아오는지 확인한다. 애니메이션의 좌우 방향이 입력과 맞는지 확인한 다음 ESC와 창 닫기를 각각 시험한다.
